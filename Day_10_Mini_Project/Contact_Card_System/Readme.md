# Contact Card System

A small JavaScript project that displays a list of contacts as cards and lets you search/filter them by city.

## Features
- Displays contact info (name, city, etc.) as styled cards
- Search/filter contacts by city in real time
- Built using arrays of objects, `.filter()`, and DOM manipulation

## Tech Stack
- HTML5
- CSS3
- JavaScript (ES6+)

## What I Learned
- Working with arrays of objects
- Filtering data based on user input
- Dynamically creating and updating DOM elements

## Run It
Open `index.html` in a browser — no build step required.
