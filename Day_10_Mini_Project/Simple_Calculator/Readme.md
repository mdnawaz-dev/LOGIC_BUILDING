# Simple Calculator

A basic calculator built with vanilla JavaScript, handling the four core operations plus edge cases like division by zero.

## Features
- Addition, subtraction, multiplication, division
- Handles division by zero gracefully (no crash, shows an error instead of `Infinity`/`NaN`)
- Real-time input via button clicks

## Tech Stack
- HTML5
- CSS3
- JavaScript (ES6+)

## What I Learned
- Handling user input and events
- Basic error handling (division by zero)
- DOM manipulation for live output updates

## Run It
Open `index.html` in a browser — no build step required.
